# Static Site Generator

A small Python static site generator that converts Markdown into HTML pages. It supports headings, paragraphs, lists, quotes, code blocks, links, images, and inline formatting.

This project was built as part of the [Boot.dev Build a Static Site Generator in Python](https://www.boot.dev/courses/build-static-site-generator-python) course.

## Usage

Run the local server:

```sh
./main.sh
```

Build the site for GitHub Pages:

```sh
./build.sh
```

The generated site is written to `docs/`.
